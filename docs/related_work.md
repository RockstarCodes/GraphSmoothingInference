## Closest existing methods

* **Closest pipeline:** Correct & Smooth [7] — a graph-agnostic base model followed by graph smoothing. It has no fairness analysis.
* **Closest fairness-aware edge modification:** FairDrop [5] (and CrossWalk [9]) — down-weighting homophilous/same-group edges to counter homophily, but during representation learning.
* **Closest fairness-aware pairwise graphical model:** FairPSL [11] — fairness constraints in a hinge-loss MRF with MAP inference.
* **Closest reproduced method:** FairWalk [3], re-implemented from the paper description (`src/embeddings/random_walks.py`), because it is the problem's named embedding-level mitigation and its code path is fully CPU-reproducible. FairGNN [4] was **not** reproduced: the released code pins torch 1.2.0 and DGL 0.4.3 (README) and its own Pokec sensitive attribute is region, not gender. We therefore report it as "not feasible in this environment" in the requirements matrix rather than calling a substitute a reproduction.

## Research gap analysis

1. **What is known.** Random-walk embeddings encode homophily [1,2]; group-aware walks or edge reweighting reduce group information/bias in embeddings [3,5,9]; graph smoothing after a simple base model is competitive with GNNs [7]; fairness can be imposed inside message passing [8] or in relational MAP inference [11]; EOpp/EO are well-defined decision criteria with post-processing remedies [10].
2. **Not adequately investigated (bounded claim).** In the verified papers we did not find an evaluation that (a) holds a debiased embedding fixed, (b) adds an *explicit, normalised* pairwise CMN with *exact* marginal inference on top of it, and (c) measures how decision-level DP/EOpp change between the two stages as demographic homophily, degree imbalance and edge corruption vary. This is a statement about the 12 papers reviewed here, not a claim that no such work exists.
3. **Why existing methods do not answer the question.** FairWalk/CrossWalk/FairDrop evaluate the representation or a model trained on it, not a downstream smoother. C&S studies accuracy only. FMP and FairPSL change the inference/aggregation itself, so they cannot separate the contribution of the embedding from that of the smoothing stage.
4. **How this project differs.** We keep topology, split, forest and unaries fixed and vary only (i) the embedding (Node2Vec vs FairWalk) and (ii) the pairwise potentials (none, uniform, global scalar, homophily-constrained attenuation), with exact sum-product so differences are not approximation artefacts. HCA is FairDrop's homophily-countering idea moved to the potentials of a downstream CMN, with one parameter selected on validation under a utility constraint, and compared with a global scalar at the same tuning budget.
5. **Falsification.** The hypothesis "uniform smoothing increases the gender EOpp gap" is refuted on Pokec-z if the paired effect's 95% block-bootstrap interval excludes positive values or the Holm-adjusted test is not significant while synthetic graphs show the effect only when demographic homophily is present. The HCA contribution is refuted if HCA does not reduce the EOpp gap relative to the global-scalar ablation at matched validation utility (H4), because then any benefit is explained by weaker smoothing, not by group-aware attenuation.
